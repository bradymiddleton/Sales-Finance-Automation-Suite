# Middleton Finance Suite

A full-stack sales finance analytics portfolio built to demonstrate end-to-end data and finance skills — from raw data generation through SQL analysis, Excel financial modeling, interactive dashboards, and an AI-assisted commentary engine.

**Live demo → [bradymiddleton.github.io/middleton-finance-suite](https://bradymiddleton.github.io/middleton-finance-suite)**

---

## What This Is

This project simulates the analytical workflow of a Sales Finance Analyst supporting a global channel sales organization. It covers four core workstreams:

| Tool | What It Does |
|------|-------------|
| **Pricing & Rebate Intelligence** | Discount rate variance vs. plan, gross margin analysis, channel partner rebate accrual |
| **Deal Evaluation Scorecard** | Composite deal scoring model, live scenario analysis, approval classification |
| **Channel Sales Performance** | Rep quota attainment, month-end close template, regional variance |
| **AI Finance Assistant** | Chat interface querying all three databases, generating analyst commentary |

## The Data

All data is **fully synthetic** — generated programmatically in Python so the project runs locally without any API keys or Kaggle authentication. The schemas and business logic are modeled after three real public datasets:

| Database | Rows | Tables | Modeled After |
|----------|------|--------|---------------|
| `pricing_rebates.db` | 4,812 | transactions, rebate_tiers, discount_plan | [Superstore Sales](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final) |
| `deal_pipeline.db` | 3,000 | deals, deal_scores, approvals | [CRM Sales Pipeline](https://www.kaggle.com/datasets/agungpambudi/crm-sales-predictive-analytics) |
| `channel_sales.db` | 204 | rep_performance, quota_plan, monthly_actuals | [Salesforce Quota Data](https://www.kaggle.com/datasets/rahuldhanola/salesforce-sales-quota-data) |

The data covers:
- **12 sales reps** across 4 regions (West, East, Central, South) and 4 segments (Enterprise, Commercial, Public Sector, SMB)
- **12 channel partners** across Gold, Silver, and Bronze rebate tiers
- **5 product categories** with distinct price ranges, COGS structures, and GM targets
- **FY2023–FY2025** transaction history with seasonal patterns and realistic variance

## SQL Analysis

`03_queries.sql` contains 19 standalone queries organized into 4 sections. This file is intended to be read on its own — every query is labeled, commented, and explains what finance question it answers.

```
SECTION 1 — Pricing & Rebate Analysis         [pricing_rebates.db]
  1A  Discount rate actual vs. plan by product category
  1B  Quarterly discount trend — FY2024
  1C  Top channel partners by average discount rate
  1D  Gross margin miss vs. target by category
  1E  Estimated rebate accrual by partner
  1F  Region-level pricing discipline summary

SECTION 2 — Deal Pipeline & Approval Analysis [deal_pipeline.db]
  2A  Pipeline summary by deal stage with weighted value
  2B  Deal approval distribution by composite score band
  2C  High-value deals pending escalation
  2D  Win/loss analysis by loss reason
  2E  Rep-level deal scoring performance

SECTION 3 — Channel Sales Performance         [channel_sales.db]
  3A  Full rep scorecard — quota attainment ranked
  3B  Regional performance summary
  3C  Month-end close variance — Q4 2024
  3D  Team-level monthly revenue trend — FY2024
  3E  Quota pacing — actual vs. quarterly plan by rep

SECTION 4 — Cross-Database Snapshots          [all three DBs]
  4A  Pricing health snapshot
  4B  Deal pipeline health snapshot
  4C  Channel performance snapshot
```

To run all queries:

```bash
python 04_run_queries.py
```

## Excel Financial Model

`middleton_sales_finance_model.xlsx` is a four-sheet workbook built with `openpyxl` following standard finance color-coding conventions:

| Color | Meaning |
|-------|---------|
| **Blue text** | Hardcoded input — editable for scenario analysis |
| **Black text** | Formula — do not edit directly |
| **Green text** | Cross-sheet reference link |
| **Yellow background** | Key assumption requiring periodic review |

**Sheets:**

- **Assumptions** — all model inputs in one place (discount caps, GM targets, rebate rates, deal scoring weights)
- **Pricing & Rebates** — discount variance by category, quarterly trend, partner rebate accrual schedule
- **Deal Scorecard** — scenario model with discount sensitivity, top 80 deals scored and classified
- **Channel Performance** — rep scorecard, month-end close template with Q4 actuals vs. plan

## Dashboards

All four dashboards are standalone HTML files that run in any browser — no server, no build step, no dependencies to install. They share the same dark enterprise aesthetic and connect via the top navigation bar.

**Dashboard 1 — Pricing & Rebate Intelligence**
- KPI cards: total net revenue, blended discount rate, avg gross margin, rebate accrual
- Bar/line combo chart: net revenue by category with GM% overlay
- Line chart: actual vs. plan discount rate by quarter
- Tables: category discount variance, partner rebate schedule
- AI panel: pre-loaded analyst commentary on pricing trends

**Dashboard 2 — Deal Evaluation Scorecard**
- Live scenario model: adjust discount rate, deal size, and COGS — GM% and recommendation update in real time
- Donut chart: Auto-Approve / Escalate / Reject distribution
- Horizontal bar chart: pipeline value by stage
- Filterable deal table: color-coded by recommendation, with score bars

**Dashboard 3 — Channel Sales Performance**
- Horizontal bar chart: quota attainment by rep, color-coded by performance band
- Line chart: monthly team actual vs. plan — FY2024
- Rep scorecard table: quota, actual, attainment %, win rate, avg discount, avg GM%
- Month-end close template: switchable Oct / Nov / Dec 2024 with beat/miss status

**Dashboard 4 — AI Finance Assistant**
- Chat interface with sidebar showing connected databases and row counts
- 6 sample prompts covering pricing, deals, rebates, and rep performance
- Mock AI responses grounded in real FY2024 numbers from all three databases
- Pre-loaded API key field (demo mode — no live API calls required)

## How to Run Locally

**Prerequisites:**

```bash
pip install pandas numpy faker openpyxl
```

**Step 1 — Generate data and build databases:**

```bash
python 01_generate_and_load_data.py
```

This builds all three SQLite databases in `databases/` and exports CSVs to `exports/`.

**Step 2 — Run SQL analysis:**

```bash
python 04_run_queries.py
```

Executes all 19 queries and prints formatted results to console.

**Step 3 — Open dashboards:**

Open `index.html` in a browser. All four dashboards and the Excel model are linked from the landing page.

> Note: The databases use a fixed random seed (`numpy.random.seed(42)`) so results are deterministic — every run produces the same data.
